## Brand & Style

This design system targets mid-market to enterprise accounting, supply chain, and fiscal operations. The design personality is authoritative, precise, and dependable. It reconciles high-density information architecture with the crisp precision of contemporary utility-first enterprise standards. 

Rooted in a deep forest green primary and energetic emerald accents, the visual tone balances financial seriousness with active clarity. Interfaces are constructed around high data density, structured cards, fine-line borders, clear temporal context, and immediate action triggers. Every dashboard widget and data visual directly pairs informational clarity with operational triage—shifting users seamlessly from observation to resolution.

## Colors

The palette employs dark forest green as the foundational brand authority, paired with vivid emerald and mint tones for actionable elements and upward trends. 

- **Primary (`#1E4B3D` / `#1B3F34`)**: Serves as the primary brand signature, active states, key primary buttons, and hero KPI surfaces.
- **Secondary (`#10B981` / `#059669`)**: Used for growth deltas, success tags, positive delta markers, and financial trend lines.
- **Shell Contrasts**: The left navigation shell operates on a rich, dark carbon-green canvas (`#0F1916`), providing contrast against the crisp, neutral light workspace canvas (`#F8FAFC`).
- **Semantic Feedback**: Amber (`#F59E0B`) highlights system session warnings and pending reconciliations; Rose (`#F43F5E`) identifies overdue invoices, liabilities, and negative cash balances; Sky (`#0EA5E9`) represents auxiliary chart series and general metrics.
- **Data Neutrality**: Tabular and structural borders use strictly calibrated zinc and slate tints (`#E2E8F0`, `#CBD5E1`) to guarantee high-density readability without visual vibration.

## Typography

The typographic hierarchy pairs **Plus Jakarta Sans** for prominent headers, metric values, and navigation titles with **Inter** for dense transactional tables, data labels, and microcopy. 

- **Numerical Display**: Metric displays prioritize clean alignment and financial scannability. Numbers and currency notations (`Rp`, `,00`, `M`) maintain tabular figures to prevent jitter during updates.
- **Section Dividers & Overlines**: System section groups (e.g., `TRANSAKSI`, `MASTER`) use uppercase tracked micro-labels (`label-caps`) with 0.08em letter spacing to establish hierarchy across navigational drawers.
- **Contextual Footnotes**: Chart disclaimers and accounting guidance leverage `body-xs` in muted slate (`#64748B`), preserving clarity while retaining secondary status.

## Layout & Spacing

This design system implements a strict enterprise grid designed for data-dense dashboards:
- **Application Shell**: A persistent 240px dark fixed sidebar coupled with a 56px sticky top navigation bar hosting global contextual search, quick actions (`+ Buat`), session state, and user profiles.
- **Dashboard Canvas**: Uses a fluid 12-column layout with 16px to 20px gutters. Standard content modules span 3 columns (KPI metrics), 6 columns (side-by-side analytical charts), 8 columns (primary timeline trend), and 4 columns (operational action queues like `Perlu perhatian`).
- **Vertical Rhythm**: A strict 4px/8px base spacing grid dictates internal card padding. Cards maintain 16px to 20px internal padding, keeping components compact while allowing full visibility of critical financial ledgers.
- **Responsive Adaptations**: On viewport widths below 1024px, the 4-column KPI row wraps into a 2x2 matrix, collapsing to a single-column stack below 640px. The persistent sidebar folds into an off-canvas drawer.

## Elevation & Depth

Visual hierarchy is communicated via clean structural containment, high-contrast borders, and minimal soft ambient depth:

- **Border-First Structure**: Elevation primarily relies on hairline borders (`1px solid #E2E8F0`) rather than drop shadows. This ensures visual crispness across high-DPI enterprise displays and avoids visual clutter in multi-card dashboard rows.
- **Subtle Surface Elevation**: Cards, modals, and popover panels use a fine diffused shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **System Banners & Floating Modals**: Banners (e.g., connection and session warnings) are rendered directly into the canvas grid with subtle borders and 0px elevation to reinforce operational integration. Dropdowns and date pickers float using `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)` with a solid `#FFFFFF` surface and `#CBD5E1` outline.
- **Hero KPI Elevation**: Distinct highlighted KPI cards (such as cash position) invert elevation using a saturated dark forest green background (`#1B3F34`) with an inset border (`1px solid #2D6A4F`) to instantly anchor user attention.

## Shapes

The interface balances sharp enterprise utility with clean, modern ergonomics:
- **Corner Radii**: Standard components (cards, dialogs, inputs, buttons) implement a cohesive 8px (`0.5rem`) corner radius. 
- **Sub-components & Badges**: Small status badges, count indicators, and pill tags use 6px (`0.375rem`) or full circular pill radii (`9999px`) for numeric notification markers.
- **Inner Embeds**: Sparkline containers, input field wrappers, and nested data table surfaces reflect internal 6px radii to match card containers.

## Components

### Buttons
- **Primary**: Solid background (`#1E4B3D`), hover state (`#16382E`), active state (`#112922`). Text is white (`#FFFFFF`) medium 13px with an 8px border-radius.
- **Secondary / Outline**: Clean border (`1px solid #E2E8F0`), white surface, text `#0F172A`. Hover transitions to background `#F1F5F9`.
- **Ghost / Table Action**: Minimal borderless buttons (e.g., `Periksa >`, `Lihat rincian >`) with text `#1E4B3D` or muted `#475569`, switching to brand-tinted background `#F0FDF4` on interaction.

### KPI Metric Cards
- **Structure**: Header with icon badge and metric title, central financial figure formatted with currency symbols and decimals, subtext indicating reference dates, and a delta indicator (`+115,1%`).
- **Sparklines**: Integrated inline SVG sparklines embedded in the lower portion of cards, with smooth stroke tracking and terminal node markers.
- **Featured Accent State**: Optional primary inversion with background `#1B3F34`, white text, and mint sparkline strokes (`#34D399`).

### Form Controls & Date Selectors
- **Input Fields**: 36px standard compact height, `1px solid #E2E8F0`, rounded 8px, interior font 13px. Focus states display an emerald focus ring (`ring-2 ring-[#10B981]/20 border-[#10B981]`).
- **Dropdowns & Filters**: Composite trigger with label, value, and chevron indicator. Includes inline presets (`Bulan acuan December 2026`, `Rentang tanggal`).

### Tables & Data Grids
- **Header Cells**: 32px height, uppercase 11px font (`label-caps`), text `#64748B`, background `#F8FAFC`, hairline bottom border `#E2E8F0`.
- **Body Rows**: 40px compact row height, alternating or clean white rows with hover highlight `#F8FAFC`. Monospaced formatting for document numbers (`INV-00056`).
- **Footer Pagination**: Embedded row counts (`2 baris · Halaman 1 / 1`) paired with compact previous/next pagination controls.

### Badges & Notification Tags
- **Status Badges**: Semi-transparent background with high-contrast text. Success uses `#ECFDF5` fill with `#059669` text; Danger uses `#FFF1F2` fill with `#E11D48` text.
- **Count Pills**: Circular high-visibility badges (`99+`) in vibrant rose `#F43F5E` positioned over navigational triggers.

### Charts & Visualizations
- **Combo & Line Charts**: Crisp axes with `#94A3B8` labels and subtle horizontal grid lines (`#F1F5F9`). Series colors adhere to palette tokens (`chart-series-1` to `chart-series-5`).
- **Donut Visuals**: High-contrast central summary value (e.g., `Saldo neto 194,1 M`) with legend breakouts highlighting negative vs. positive balances.
